# Typesong for Mac: launch clip plan (draft)

Goal: one short clip that says "Typesong is on Mac now" and makes people want to hear it. Every sound in it
is Typesong itself, as in the README promo. Nothing gets posted without Miguel's yes; the look and cut are his call.

**Length and formats:** 20 to 25 seconds. One 16:9 master for X, Reddit and the GitHub README, and a 9:16 crop
for Shorts, Reels and TikTok. Sound on, with captions burned in, since most feeds start muted.

**Shot list (default, change freely):**
1. 0 to 3 s: the DMG opens, Typesong is dragged to Applications. Caption: "Typesong is on Mac."
2. 3 to 6 s: menu bar click, the Typesong menu opens, Lofi is picked.
3. 6 to 13 s: typing a real message in Notes or Slack. Slow, then fast, so the energy lift is audible.
   Caption: "Every key plays a note. Your speed sets the energy."
4. 13 to 17 s: switch to Instruments, piano. A few words typed. Caption: "Seven sounds."
5. 17 to 21 s: Claude Code working in Terminal with Agent music on, ending on the done chord.
   Caption: "It can play your AI agent too."
6. 21 to 24 s: end card. "Typesong. Free for Mac, Windows and Linux." plus the repo or Pages link.

**Capture:** record at 2x on the MacBook with system audio. The macOS screenshot tool (Shift Command 5) records
no system audio, so use OBS (ScreenCaptureKit audio) or QuickTime with an audio loopback. Clean desktop,
notifications off (Focus), a calm wallpaper, menu bar trimmed.

**Reuse:** the existing README promo already proves the sound. If time is short, the fastest version is shot 1 and
shot 2 cut in front of the existing promo, with the end card changed to include Mac.

**Where it goes (each needs a yes):** README video swap, the v0.1.1 release page, X, r/macapps, Show HN, Product Hunt.
