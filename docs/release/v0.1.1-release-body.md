A hardening release: fixes and safety improvements across the app, found in a full review of the code. Nothing about how Typesong sounds has changed, except that guitar notes now fade out cleanly.

**Try it in your browser first:** https://roybogs.github.io/typesong/

## Downloads

- **Mac (macOS 14 or later, Apple Silicon and Intel):** `Typesong-0.1.1.dmg`. Signed and notarized by Apple, so it opens like any other app. Open the DMG, drag Typesong to Applications, then open it from there. It lives in your menu bar. The first time you type, macOS asks to allow **Input Monitoring** for Typesong: that's how it hears which key you pressed (never what you typed). `Typesong-0.1.1.dmg.sha256` has its checksum.
- **Windows 10/11:** `Typesong_0.1.1_x64-setup.exe`. This build isn't code-signed yet, so Windows may say it "protected your PC": choose **More info → Run anyway**. It installs for your user only; no admin needed.
- **Linux (x86-64):** `Typesong_0.1.1_amd64.deb` for Debian/Ubuntu, or `Typesong_0.1.1_amd64.AppImage` for anything else (`chmod +x` it, then run). For the keyboard to work on Wayland, add yourself to the `input` group: `sudo usermod -aG input $USER`, then log out and back in.

`SHA256SUMS.txt` has checksums for the Windows and Linux files.

## Fixed

- **Windows:** after locking the screen (Win+L or Ctrl+Alt+Del), Typesong could think Win or Ctrl was still held and go silent until you pressed it again.
- **Linux:** keyboards that disconnect and come back (Bluetooth sleep, a USB replug) are picked up again.
- **Guitar:** low strings no longer stop with a click at the end of a note.
- **Agent music:** it could stay off after a restart if its local port was briefly busy; it now retries. Parallel tool calls no longer play the same text twice.
- **Connect Claude Code:** a `settings.json` that couldn't be read is never overwritten, a symlinked one stays a symlink, file permissions are kept, and the backup is private to you.
- **Stability:** a burst of missed beats after a stall, a slow memory leak in the web version, and log files that grew forever.

## Safer

- The agent-music port (`127.0.0.1:47321`, never reachable from the network) now refuses requests from web pages open in your browser, anything that isn't JSON, and oversized or stalled connections.
- A content security policy locks down the Windows/Linux engine page.
